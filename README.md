# Social Media Profile 🌐

Página pessoal de redes sociais - Personal social media profile page.

## 📋 Descrição

Uma página web responsiva que apresenta Bruno Henrique com links para suas principais redes sociais.

## 🎯 Características

- ✅ Design responsivo (mobile-friendly)
- ✅ Foto de perfil circular
- ✅ Links para Instagram, Facebook, TikTok e YouTube
- ✅ Estilo visual atrativo com cores vibrantes

## 🛠️ Tecnologias

- HTML5
- CSS3
- Font Awesome (ícones)

## 📱 Como usar

1. Faça o clone ou download do repositório
2. Adicione as imagens necessárias:
   - `bruno.jpg` - Foto de perfil (150x150px)
   - `instagram.png` - Ícone do Instagram
   - `facebook.png` - Ícone do Facebook
   - `tiktok.png` - Ícone do TikTok
   - `youtube.png` - Ícone do YouTube
3. Abra o arquivo `social.html` no seu navegador
